# SudeepSarkar.github.io

Personal academic page of Sudeep Sarkar. The whole site is one file, `index.html`.

## Publish on GitHub Pages

1. Sign in to GitHub as SudeepSarkar and create a new public repository named exactly `SudeepSarkar.github.io`.
2. Upload `index.html`, `.nojekyll` and `portrait.jpg` (a 4:5 portrait, about 960 x 1200 pixels) to the repository root.
3. In the repository, open Settings, then Pages. Under "Build and deployment", choose "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site appears at https://sudeepsarkar.github.io within a few minutes.

## Updating

Edit `index.html` and commit. Citations in the text link to the numbered list under "Selected publications"; add a new paper to that list and cite it as `<sup class="cite"><a href="#ref-N" data-ref="N">[N]</a></sup>`.

## Custom domain (optional)

Buy a domain (for example sudeepsarkar.com), add it under Settings, Pages, Custom domain, and follow GitHub's DNS instructions.
